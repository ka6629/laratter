# Phase01 画面収録 操作内容

サークル機能による公開範囲の制御を、3つのアカウントで確認しています。

## アカウント1(ユーザー名:aiueo)
ツイートを投稿する側のアカウントです。

1. サークルに追加するアカウントを選択する
2. 公開範囲(全体公開 / サークルのみ)を選択する
3. ツイートを投稿する

## アカウント2(ユーザー名:kakikukeko)
アカウント1のサークルに追加されているアカウントです。

- アカウント1の「全体公開」と「サークルのみ公開」のツイートをすべて閲覧できる

## アカウント3(ユーザー名:sasisuseso)
アカウント1のサークルに追加されていないアカウントです。

- アカウント1の「全体公開」のツイートのみ閲覧できる
- 「サークルのみ公開」のツイートは閲覧できない
