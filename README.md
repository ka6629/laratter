受講番号：6th-20

## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」に，**特定のユーザーのみが閲覧できるサークル機能**を追加しました．

- サークルに追加したアカウントだけがツイートを閲覧できる
- 公開範囲(全体公開/サークルのみ)を選択できる

インスタの親しい友達のような機能があると他ユーザーと交流がしやすくなるのではと思い，実装しました．サークル機能を選んだ理由は，ユーザー同士の多対多のリレーションになるため，講義で学んだフォロー機能やいいね機能の仕組みを応用できると考えたからです．

## 2. こだわった点・苦労した点

- サークルに入れられるのはフォロワーだけにし，フォロワー以外のユーザーは選べないようにした．
- 一覧だけでなく，検索・プロフィール・詳細ページでも，サークル外のユーザーにはツイートが表示されないようにした．
- 閲覧制限を一覧・検索・プロフィール・詳細・いいね・コメントのすべてに入れる必要があり，抜けがないか確認するのに時間がかかった．

## 3. 操作方法

1. サイドバーの「サークル」をクリックし，サークル画面を開く
2. フォロワーの一覧から，サークルに入れたいフォロワーにチェックを入れ，「保存」ボタンを押す
3. 「Tweet作成」画面でツイートを入力し，公開範囲で「全体に公開」か「サークルのみに公開」を選んで投稿する
4. 「サークルのみに公開」を選んだツイートには「サークル」と表示され，サークルに入れたフォロワーと自分だけが閲覧できる
